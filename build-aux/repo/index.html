Fractal+

Fractal, the GNOME Matrix app, with voice calls and screen sharing that work with Element Call.

Install Fractal+ (opens in GNOME Software or KDE Discover), or run:

flatpak install --from https://5tn1rczrs79vaefuucrb.github.io/fractalplus/fractalplus.flatpakref

Updates then arrive with flatpak update or in your software app.
